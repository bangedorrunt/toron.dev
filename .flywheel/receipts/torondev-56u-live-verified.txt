THE FIX, IN ONE PLACE
apps/toron-dev/scripts/check-freshness.mjs and chiebukuro docs/guides/check.mjs
both strip code spans and straight, curly, and single-quoted runs before matching
a number against the pin:

    const NOT_AN_ASSERTION = [
      /`[^`]*`/g,
      /"[^"\n]*"/g,
      /“[^”\n]*”/g,
      /'[^'\n]*'/g,
    ];

The site gate keeps a self-test that refuses to trust its own run: it exits 1 if a
quoted figure is read as an assertion, and exits 1 if the strip eats a genuine
one.
