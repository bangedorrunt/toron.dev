The bug, as the reader met it. The home page's plane strip is four links to four
repositories. The Beads one pointed at https://github.com/bangedorrunt/br. Asked
anonymously: br 404, beads 200. Asked with `gh api`: bangedorrunt/br => "gh: Not Found
(HTTP 404)", bangedorrunt/beads => public, Rust, the tracker fork. The beads checkout's
own origin remote has said bangedorrunt/beads throughout, so the site was the last place
still spelling the old name, and it was spelling it to every visitor.

asks `gh` for each repository, and asserts the built home page carries every URL.
