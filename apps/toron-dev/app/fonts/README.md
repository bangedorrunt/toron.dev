# Operator fonts

Local, self-hosted copies of Operator SSM Plus (Book/Medium/Bold) and Operator
Mono SSM Plus (Book/Medium/Bold), sourced from the sibling
`operator-mono-font` project and loaded through `next/font/local`.

The source build is licensed for personal use and is not for redistribution.
These files are served only by this personal site. Keep them out of standalone
font packages or public asset bundles.
