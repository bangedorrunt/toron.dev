toron is the signed transport and record layer: mail, identity, receipts, reservations, and the durable archive
underneath the other three planes. It is the clearest plane to start with, because a mailbox is something you can
watch work in ten minutes.

## Start on this site

<Card title="First signed handoff" href="/docs/guides/first-signed-handoff">
Install the daemon, register a pin, and exchange a sealed message with a receipt. Every step shows the output it
produces.
</Card>

<Card title="Survive a crash" href="/docs/guides/crash-recovery">
Kill the daemon mid-workflow and watch the run resume instead of restarting.
</Card>

<Callout title="What this site adds">
The reference grid for the 38-tool MCP surface is generated from `catalog/toron-mcp.json` on every build and pinned
by a freshness gate, so a count on this site cannot quietly disagree with the product. The guide table above is
checked the same way: a guide added in the toron repository without a row here fails the build.
</Callout>
