beads is the work ledger: work items, dependencies, verification gates, and the close evidence that makes a claim
checkable later. It is the plane that decides whether work is actually finished.

## Every canonical guide

Every guide below is read here in full. The text is projected from `beads/docs/guides/` into this site and hashed on both sides, so the beads
repository stays the only place it is written and a copy edited here instead of there fails the build (ADR-0006).
Those guides are written as plain Markdown, and this site compiles MDX, so the projection escapes the two
characters that mean something else in MDX and quotes one frontmatter value. Commands, flags, and shown output are
untouched. The Canonical column names the file each page came from.

<Callout title="Why the ledger is not bookkeeping">
  An item closes only on a passing gate row plus a commit whose message names the item, and the
  close command resolves that commit read-only. A close you have to argue for is a close the record
  does not support, which is the whole point of the [walkthrough](/docs/guides/close-with-evidence)
  on this site and the reason toron reserves file paths for it.
</Callout>
