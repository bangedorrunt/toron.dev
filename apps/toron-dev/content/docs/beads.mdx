beads is the work ledger: work items, dependencies, verification gates, and the close evidence that makes a claim
checkable later. It is the plane that decides whether work is actually finished.

## Start on this site

<Card title="Close with evidence" href="/docs/guides/close-with-evidence">

</Card>

<Callout title="Why the ledger is not bookkeeping">
An item closes only on a passing gate row plus a commit whose message names the item, and the close command
resolves that commit read-only. A close you have to argue for is a close the record does not support, which is the
whole point of the [walkthrough](/docs/guides/close-with-evidence) on this site and the reason toron reserves file
paths for it.
</Callout>
