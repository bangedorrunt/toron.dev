chiebukuro is the stack's memory: a compiled knowledge wiki on one plane, episodic memory on the other, kept
authority-distinct. A memory conclusion is not a wiki page, and a wiki page is not a recollection.

## Start on this site

<Card title="Remember and recall" href="/docs/guides/remember-and-recall">
Read a wiki page instead of a gist, write one page of your own, and record a decision recall returns with its class
labelled.
</Card>

## Every canonical guide

Every guide below is read here in full. The text is projected from `chiebukuro/docs/guides/` into this site and
hashed on both sides, so the chiebukuro repository stays the only place it is written and a copy edited here
instead of there fails the build (ADR-0006). Those guides are written as plain Markdown, and this site compiles
MDX, so the projection escapes the two characters that mean something else in MDX and quotes one frontmatter
value. Commands, flags, and shown output are untouched. The Canonical column names the file each page came from.

<Callout title="Where the two planes disagree">
Querying both is the honest default: `chie qmd search` answers from curated pages, `chie memory recall` answers
from what was decided, and `chie qmd search --memory` spans both in one call with each hit labelled by the plane it
came from. If an answer only exists on one side, say which side it came from.
</Callout>
