# Buzz parity

Living tracker of what we **steal / adapt / reject** from [block/buzz](https://github.com/block/buzz) (and AgentMail where relevant) so agents do not re-litigate closed decisions.

**Sources of truth (toron repo):** ADR-0003 (`docs/decisions/0003-nostr-mailbox-fabric.md`) · comparison note (`docs/notes/2026-08-07-buzz-agentmail-comparison.md`) · GS-061/062 ship reports.

**Last updated:** 2026-09-25 (Melbourne AEST)

## Status legend

| Status | Meaning |
|--------|---------|
| **Landed** | Call site + tests (or live gate) on tip; do not re-implement |
| **Adapted** | Buzz pattern kept; dependency/shape changed (e.g. SQLite not Redis) |
| **Rejected** | Explicit non-goal — do not open as "Buzz has it" |
| **Hold** | Scouted / library-only / needs captain word — no invent-green |

## Explicit REJECT / HOLD (do not re-open casually)

**REJECT:** Redis presence · AgentServer · OTP · casual new Nostr kinds · Funnel · dual SoT · NIP-FI runtime · ACP / stdio harness · channel-wide chat memory · push-gateway / mobile UX · buzz-relay-mesh as default · Postgres+S3 as authority path.

**HOLD (captain word):** L1 audit TLV · Forge/NIP-34 thaw · newest-first windows / read-state snapshots · wake.sock recovery counter sprawl beyond Quiet/Live/Deaf/NeverStamped.

## How to update this page

1. **Buzz PR scouted** — add or revise a row; cite Buzz PR/SHA; set Status=Hold until a GS ship lands call sites.
2. **After a GS ship** — flip Status to Landed/Adapted/Rejected with Ship id; link the ship report path under `agent-data/grok-ship/reports/`.
3. **Never invent-green** — Landed requires call site + test (or live gate evidence). Library-only stays Hold.
4. Keep ADR-0003 Prior Art and the Aug-07 comparison note in sync when status flips.
