toron is the signed transport and record layer underneath a larger autonomous agent workflow.

## The stack

| Plane | Owns |
| --- | --- |
| **toron** | signed mail, identity, receipts, reservations, archive |
| **flywheel** | dispatch, loops, workflows, cron, coalitions |
| **beads** | claims, dependencies, verification gates, close evidence |
| **chiebukuro** | curated knowledge, episodic memory, synthesis |

Read the public [stack architecture](/architecture) first, then use the agent guide for a concrete setup path.

## Install the daemon

```bash
toron daemon install
toron daemon start
toron doctor --check
```

## Register an agent

Give the acting identity a stable adjective-noun pin:

```bash
toron agent bootstrap \
  --project <project> \
  --as <Pin> \
  --paths <glob> \
  --reason <bead-id>
```

## Send the first signed message

```bash
toron mail send \
  --project <project> \
  --as <Pin> \
  --to captain \
  --subject "[<bead-id>] starting" \
  --body "claiming <bead-id>" \
  --thread <bead-id>

toron mail inbox --since last
```
