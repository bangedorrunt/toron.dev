Packs are pure data at `.flywheel/judgment-packs/<id>.vN.yaml`. Code owns
control flow; packs only supply calibrated judgments. The loader picks the
highest `vN` per id; older versions stay on disk for audit. A judgment is an
ADR-0016 effect: it is requested by an interpreter and returns evidence as a
message; it never runs inside a reducer or becomes a routing, delivery, close,
or verification authority.

## Shaping (from the typesafe-ai skill)

- One narrow, coherent judgment per question. Split independent dimensions.
- Put the judgment in `instructions` with complete meaning — question IDs are
  for code and are not sent to the model.
- `criteria` defines each Choice/Score option 1:1 as concrete situations that
  stand on their own. Noul questions carry free guidance lines instead.
- Include a no-match outcome (`unclear`, `unprovable`) so the model is never
  forced into a false positive.
- Choice picks one of a set (its distribution compares options); Noul is one
  probability per condition; Score is a graded position for ranking.
- State uses named JSON fields (`goal.text`, `material.text`, `verify.cmd`).

## Validation

`QuestionPack::parse_yaml` enforces: non-empty id, version ≥ 1, pinned model
(never `jev-latest`), every question with id + instructions, Choice/Score
with ≥ 2 options, criteria aligned 1:1 when present. Model pin is
`jev-1.13.0` until pack re-validation CI exists.

## Mining the miss ledger

Every reclassify expand appends `&#123;ts, goal, table primitive/topology,
resolution}` to `miss-ledger.jsonl`, keyed by the parent effect key:

- `judgment miss-list` — unresolved rows (what still needs a verdict).
- `judgment miss-list --needles` — recurring unresolved `none` goals with
  counts. A recurring miss is a routing-table gap: add the needle words to
  `decide.rs`, never force-fit an `explicit none`.
- `judgment miss-resolve <effect-key> --resolution confirm|deny|raw|compose`
  — close the loop on none-path advisories (confirm/deny) or record how an
  undecided goal was actually dispatched (raw/compose).

Annotators never dispatch, hold, assign, or close. Confidence is peakedness,
not permission — low confidence escalates to muse-spark/human. Preserve the
parent effect key across retries and keep malformed, timeout, unavailable, and
unknown provider results visible; do not convert them to a green judgment.
