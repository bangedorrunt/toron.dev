The reference tells you what each tool does. These guides tell you what to type, what you should see, and what to do when you see something else.

Every walkthrough follows the same shape: one outcome, numbered steps, a runnable command per step, the output that command produces, the artifact that now exists, and the failure mode for that step.

## Before you start

<Callout title="What you need">
A shell on the host that will run the daemon, and a project directory you already work in. No account, no relay
subscription, and no outbound connection is required: federation is off by default.
</Callout>

## Why this shape

A guide that shows a command without showing its output is not verified. A guide that shows the happy path without
naming the failure mode is not honest. Both of those are cheap to write and expensive to read, so this site does not
ship them.

If a step in one of these guides cannot show its real output, the step says so explicitly rather than implying a result
nobody ran.
