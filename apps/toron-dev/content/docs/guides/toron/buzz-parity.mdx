Living tracker of what toron **steals / adapts / rejects** from [block/buzz](https://github.com/block/buzz) (and AgentMail where relevant). Any agent harness that integrates toron mail, wake, or delivery should treat this table as the closed-decision surface — do not re-litigate rows already marked Landed, Adapted, or Rejected.

**Audience:** harness authors and agents integrating Buzz-parity semantics on toron (mail settle honesty, fences, DeliveryCursor, DLQ / ProvenFailed, wake liveness). Not a Firstmate / factory / crew process doc.

## Explicit REJECT / HOLD (do not re-open casually)

**REJECT:** Redis presence · AgentServer · OTP · casual new Nostr kinds · Funnel · dual SoT · NIP-FI runtime · ACP / stdio harness · channel-wide chat memory · push-gateway / mobile UX · buzz-relay-mesh as default · Postgres+S3 as authority path.

**HOLD (needs explicit open):** L1 audit TLV · Forge/NIP-34 thaw · newest-first windows / read-state snapshots · wake.sock recovery counter sprawl beyond Quiet/Live/Deaf/NeverStamped.

## Honesty rules harnesses must keep

These are toron surface contracts. A harness that sits on toron (or mirrors Buzz-parity mail/wake) must not invent softer meanings:

1. **Settled-Delivered only after publish** — Deferred / Accepted / buffered is not Settled until the publish path completes.
2. **Exhausted Transient → ProvenFailed + DLQ** — never force-retry an Exhausted Transient batch.
3. **Fence + generation** — stale busy-owner generations cannot reclaim; Drop→Release.
4. **DeliveryCursor** — session delivery proof ≠ agent-key signature alone.
5. **Wake liveness** — Quiet / Live / Deaf / NeverStamped; never fold `.event` and `.hb` with `max` into `last_event_ms`.
6. **Presence fail-closed** — store unhealthy ⇒ not admitted; never hardcode admit-true; never Redis.

## How to update this page

1. **Buzz PR scouted** — add or revise a row; cite Buzz PR/SHA; set Status=Hold until call sites land.
2. **After a landing PR** — flip Status to Landed/Adapted/Rejected; record the ship id (e.g. GS-061/062) as a historical marker when useful.
3. **Never invent-green** — Landed requires call site + test (or live gate evidence). Library-only stays Hold.
4. Keep ADR-0003 Prior Art and the Aug-07 comparison note in sync when status flips.
